# Interactive Flash Card Prototype

This is a high-fidelity interaction prototype designed to explore contextual learning through stories, flash cards, and quizzes. The focus of this prototype is on testing interaction patterns, visual layout, and user flow rather than delivering a production-ready application.

---

## Background and Design Process

The project started with the idea of creating a **3D note-taking application**. The initial prototype was a low-fidelity wireframe emphasizing basic layout, structure, and navigation.

During early **user testing**, feedback indicated that a full 3D note-taking app might be too complex and less practical for daily learning:

- Inputting and managing notes in 3D was cumbersome.
- Users faced a steep learning curve navigating 3D space.
- Maintaining consistent study habits was challenging.

Based on this feedback, the design shifted toward a **flash card-based approach**. This direction provided a better balance between feasibility, usability, and engagement:

- Easier to implement and iterate compared to full 3D visualization.
- Aligns with common study habits and memory reinforcement techniques.
- Retains some concept linking through tags and visual clusters.

---

## Design Iterations

1. **Low-Fidelity (Initial Stage)**  
   - Basic wireframes with placeholder cards and input fields.  
   - Focused on layout, navigation, and interaction flow.  
   - No animations or detailed styling.

2. **Mid-Fidelity**  
   - Added interactive elements: clickable cards, input validation, and tag selection.  
   - Established initial visual hierarchy for content readability.  
   - Early user testing highlighted interaction pain points.

3. **High-Fidelity (Current Prototype)**  
   - Refined visual style with consistent spacing and card components.  
   - Added transitions, modals, and subtle animations to indicate user interactions.  
   - Simplified 3D visualization of knowledge clusters retained for context.  
   - Integrated story-based flash cards, quizzes, and memory hints informed by user feedback.

**User testing** played a critical role in shaping features and improving usability throughout these iterations.

---

## Prototype Features

### Home Screen
- Daily story with highlighted words.
- Learning statistics and active concept clusters.
- Scrollable cluster cards for quick access to stories.

### Explore Screen
- Search for topics and concepts.
- Browse topic cards and add them to the library.

### Add Concept
- Input new words and definitions.
- Tag assignment to organize content.
- Optional memory hints for better retention.
- Save connections to the library.

### Library
- Search and filter words by keyword or tags.
- Displays learning status of words.
- Provides clear empty state messaging when no matches exist.

### Profile
- Displays learning progress and daily goals.
- Simplified visualization of knowledge connections with nodes.

### Story & Quiz
- Interactive story content with clickable words revealing definitions.
- Fill-in-the-blank quizzes to reinforce learning.
- Feedback overlays for correct and incorrect answers.

---

## Interface Notes

- Mobile-first design simulating a device frame.
- Card-based layout for clarity and modularity.
- Smooth transitions and feedback for user interactions.
- Clear typography and spacing to prioritize readability.
- Scrollable content areas to accommodate longer stories and concept lists.

---

## Reflections

- Iterative design helped move from low-fidelity sketches to high-fidelity interactive prototypes.
- **User testing** was crucial in redirecting the project from a 3D notes app to a practical flash card system.
- Keeping the scope manageable allowed deeper exploration of interactions and usability instead of overloading features.

---

## Future Considerations

- Improve memory hint generation and study reinforcement.
- Add more flexible tagging and filtering options.
- Explore optional 3D visualizations for advanced users while keeping the default interface simple.
- Continue user testing to validate interaction patterns and learning effectiveness.
