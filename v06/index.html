UX Case Study

SceCards

A flashcard system exploring contextual memory instead of rote repetition.

1. Problem Statement

How might we help college students retain abstract vocabulary and knowledge without relying on repetitive memorization techniques?

2. Value Proposition

SceCards is a flashcard-based learning tool that allows students to connect isolated terms through contextual usage and narrative exposure, improving long-term recall.

3. Key Features

  • Custom flashcard creation
  • Context-based exposure instead of fill-in-the-blank
  • Lightweight review sessions
