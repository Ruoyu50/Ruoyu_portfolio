UX Portfolio Project

单词卡 App

一个帮助大学生通过生活情境自然接触和内化单词的语言体验平台。

[占位：高保真设备原型]

Problem Statement

挑战

大学生在传统单词学习中容易疲劳，因为死记硬背缺乏情境和体验感。

我们如何帮助大学生以更自然、有情境、且低消耗意志力的方式接触单词？

Value Proposition

解决方案

Contextual Flashcards 是 语言体验平台， 让 大学生 在 不断变化的生活情境中自然遇见并内化单词。

Competitors

竞品分析

产品 学习方式 情境 重复机制 情感压力 总结
Anki强制回忆❌高中高效但消耗意志力
Quizlet测试型❌高中偏应试
Duolingo游戏化伪情境高高易焦虑
看美剧自然接触✅低低无结构引导
本产品情境体验✅低低平衡结构与自然性
